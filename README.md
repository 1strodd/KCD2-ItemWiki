# KCD2 — предметы и хэши

Страница-справочник для администраторов серверов **Kingdom Come: Deliverance II**:
одежда, броня, оружие и боеприпасы с иконками и хэшами (UUID) для выдачи.
Одинаковые по названию предметы разных цветов собраны в одну карточку, у каждого варианта свой хэш.

**Открыть:** `index.html` (работает локально без сервера; иконки подгружаются из интернета).

## Возможности
- Поиск по названию, фракции, UID и хэшу; фильтр по категории
- Клик по строке копирует хэш; режимы «Список» и «Галерея»
- Вкладка «Сэты» — предметы одной фракции/герба (Leipa, Kuttenberg и т.д.)
- Избранное, недавние и набор для копирования нескольких хэшей сразу
- Увеличенная иконка при наведении, горячие клавиши: `/` — поиск, `Esc` — очистить

## Источник данных
[Kingdom Come: Deliverance Wiki (Fandom)](https://kingdomcomedeliverance.fandom.com) — модули `Module:ItemData*`.
Вики общая для KCD1 и KCD2: данные первой игры (`Module:ItemData/KCD*`) при сборке исключаются.
Данные неофициальные (собраны сообществом) и могут отставать от патчей — проверяйте критичные хэши в игре.

## Пересборка
Нужен Node.js 18+.

```bash
node build.js            # скачать данные с вики и собрать index.html (несколько минут)
node build.js --cached   # пересобрать index.html из items.json без запросов в сеть
```

Список категорий, которые попадают в выдачу, задаётся в `build.js` (`KEEP_TAGS`).
